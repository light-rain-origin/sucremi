# 路线图（ROADMAP）

> 以下为方向性规划，非承诺；每一阶段完成后依任务书推进，不提前实现未规划能力。

## 阶段 0 —— 工程初始化（当前，已完成）

- [x] Vue 3 + TypeScript 前端骨架
- [x] Spring Boot 后端骨架（Java 25 / Boot 4.1.1）
- [x] MySQL 本地配置约定 + Flyway 首个迁移
- [x] 统一 API 响应结构 + 全局异常处理
- [x] 健康检查接口 `/api/v1/health`
- [x] 前端开发代理访问后端
- [x] 项目文档（产品/架构/数据库/API/开发/路线图）
- [x] 前后端各一组可运行测试

## 阶段 1 —— 基础工作台（规划中）

围绕“防遗忘”核心：

- 项目/任务的创建与进度记录
- 设计决策记录（为什么这么选）
- 资料归集（链接、文档、片段）
- “下一步行动”清单

落地时引入第一张业务表，并执行用户数据隔离约定（`user_id` 关联 `app_user`）。
