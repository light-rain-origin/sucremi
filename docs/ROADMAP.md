# 路线图（ROADMAP）

> 以下为方向性规划，非承诺；每一阶段完成后依任务书推进，不提前实现未规划能力。

## 阶段 0 —— 工程初始化（已完成）

- [x] Vue 3 + TypeScript 前端骨架
- [x] Spring Boot 后端骨架（Java 25 / Boot 4.1.1）
- [x] MySQL 本地配置约定 + Flyway 首个迁移
- [x] 统一 API 响应结构 + 全局异常处理
- [x] 健康检查接口 `/api/v1/health`
- [x] 前端开发代理访问后端
- [x] 项目文档（产品/架构/数据库/API/开发/路线图）
- [x] 前后端各一组可运行测试

## 阶段 1 / P0 —— 基础工作台 MVP（已完成，任务书 T1–T12）

把「项目」这个容器立起来，并打通身份与数据隔离这条底座 —— 后续所有「防遗忘」记录都挂在
项目之下，所以先做容器，再做记录。

- [x] 身份与数据归属：`CurrentUserResolver` + `local` 开发期固定身份 + 失败关闭兜底
      （决策记录 `docs/decisions/0001-identity-and-data-ownership.md`）
- [x] 项目模块：列表（分页 / 状态 / 归档过滤）、详情、创建、编辑、归档 / 取消归档
- [x] 概览统计接口 `/api/v1/dashboard/summary`
- [x] 前端三个页面：概览、项目列表、项目详情
- [x] 第一张业务表 `project`（Flyway `V3__create_project.sql`），携带 `user_id` → `app_user.id`
- [x] 测试矩阵：后端接口 / 服务 / 领域，前端组件 / 布局 / 状态 / 页面 / 工具
      （覆盖清单见 `docs/DEVELOPMENT.md` 的「P0 测试矩阵」）

## 阶段 2 —— 防遗忘核心（进行中）

阶段 1 只有「项目」这个空容器：能建、能改、能归档，但还回答不了最初那四个问题 ——
做到哪一步了、当时为什么这么选、资料放在哪、接下来做什么。已完成第一步「上下文恢复 P0」：

- [x] 检查点手动记录、历史列表与最新检查点读取
- [x] 下一步行动创建、状态更新与排序
- [x] 基于最新检查点与行动的规则式恢复摘要
- [x] 首页继续工作卡片与项目恢复详情页
- [x] Flyway V4：`project_checkpoint`、`project_action`

后续任务书再逐项推进，尚未实现的方向包括：

- 进度 / 活动时间线
- 设计决策记录（为什么这么选）
- 资料归集（链接、文档、片段）

项目详情页已为这几项留了占位卡片（「任务与下一步」「进度 / 活动时间线」「检查点历史」
「决策记录 & 知识资料」）。落地时按任务书逐项推进，不一次性全做。
