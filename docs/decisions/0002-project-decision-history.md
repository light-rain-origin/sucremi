# ADR 0002：项目决策使用不可变后状态快照

- 状态：已采纳
- 日期：2026-10-15

## 背景

项目决策会随着实践补充、纠正或被新方案取代。直接覆盖当前记录会丢失当时的选择及其理由；在业务活动中复制完整正文又会产生重复数据并扩大敏感内容暴露面。

## 决策

- `project_decision` 保存当前状态，`project_decision_revision` 追加保存完整的后状态快照。
- 新建记录生成版本 1；实质性修改、采纳、替代和软删除生成下一版本。当前行版本号与最新快照版本一致。
- 当前记录更新、快照插入和活动事件写入处于同一事务。
- 编辑接口要求 `expectedVersion`，通过条件更新检测并发冲突。
- 替代关系只由旧决策指向同项目中新建的已采纳决策；旧记录不被覆盖或删除。
- 活动事件只保存决策 ID、截短标题和关联 ID，不保存背景、选择理由或其他正文。

## 结果

历史可直接审阅且没有回滚入口；并发冲突需要客户端重新读取后重试。活动时间线保持轻量，决策正文仍以决策和版本表为唯一来源。
