# 产品说明（PRODUCT_SPEC）

## 定位

Sucremi 是**个人开发工作台**。核心解决的问题：项目中断一段时间后，重新捡起时忘记了

- **进度**：做到哪一步了；
- **设计原因**：当时为什么这么选；
- **资料位置**：相关链接、文档、片段放在哪；
- **下一步行动**：接下来该做什么。

## 范围与阶段

- 第一版（V1）只服务**单个用户**，优先建设**私人工作台**。
- 公开网站（对外展示 / 博客等）后续阶段再做。
- 不在早期实现：AI、多 Agent、公开博客、复杂权限。

## 阶段 0（当前）目标

仅完成**工程初始化**：

1. 前后端工程骨架可独立安装、构建、启动。
2. 统一 API 响应结构与全局异常处理。
3. 健康检查接口 `/api/v1/health`。
4. MySQL + Flyway 本地可用，首个迁移可执行。
5. 前端开发代理可访问后端。
6. 完整开发文档与本地启动/测试说明。
7. 至少各一组可运行的前后端测试。

阶段 0 不实现任何业务功能。完成后停下，等待下一阶段任务书。

## 后续方向（非承诺，详见 ROADMAP）

项目/任务管理、进度与决策记录、资料归集、下一步行动清单等围绕“防遗忘”的能力。
